# 🏰 中世纪王朝 · 交易分析器

> 一款专为《中世纪王朝》玩家设计的物品价格管理、配方利润计算与交易决策工具。

通过直观的表格界面，你可以轻松管理游戏中的物品、配方，并实时计算不同技能等级下的利润，助你高效规划生产与贸易。

---

## ✨ 功能特性

- **物品管理**  
  - 添加、编辑、删除物品（支持自定义分类，如“矿产”、“食材”、“染料”）  
  - **直接点击单元格修改**——点击物品名称或价格即可编辑，无需删除重加  

- **配方管理**  
  - 灵活的材料输入格式：支持空格、逗号、顿号分隔（如 `原木1 青铜锭2` 或 `铁矿石 3, 云杉树皮 40`）  
  - **自动计算利润**：基于成品基础价和技能等级（0~3级，系数 1.0~1.3）实时更新售价与利润  
  - 配方成本自动汇总，利润一目了然  

- **数据持久化**  
  - 后端使用 **SQLite** 数据库，所有数据安全保存，重启不丢失  
  - 提供一键备份命令：`npm run backup`（备份至 `server/backups/` 目录）  

- **筛选与查看**  
  - 按分类快速筛选物品和配方  
  - 点击配方中的材料列，弹窗显示所有材料单价，方便核对成本  

---

## 🛠️ 技术栈

| 端 | 技术 |
|---|---|
| **前端** | Vite + 原生 JavaScript (ES Module) |
| **后端** | Node.js + Express |
| **数据库** | SQLite (better-sqlite3) |
| **并发工具** | concurrently (一键启动前后端) |

> 项目采用前后端分离架构，前端负责界面交互，后端提供 RESTful API 并操作数据库。

## 🚀 快速开始

### 1. 克隆项目
```bash
git clone https://github.com/Marcus-LamMan/medieval-dynasty-trade.git
cd medieval-dynasty-trade
```

### 2. 安装依赖
```bash
# 安装前端依赖
npm install

# 进入 server 目录并安装后端依赖
cd server
npm install
cd ..
```

### 3. 初始化数据库（首次运行）
```bash
cd server
node init-db.js
cd ..
```
该脚本会自动创建 `database.db` 并插入示例数据（包含“黑色染料”配方等）。

### 4. 启动应用（推荐）
```bash
npm run dev:all
```
此命令会同时启动：
- 前端开发服务器（默认 `http://localhost:5173`）
- 后端 API 服务（默认 `http://localhost:3000`）

也可以分别启动：
```bash
npm run dev     # 仅前端
npm run server  # 仅后端
```

### 5. 访问应用
打开浏览器访问 `http://localhost:5173`，开始管理你的中世纪王朝数据！

## 📖 使用指南

### 添加物品
- 在“物品价格库”区域，填写名称、价格和分类，点击“添加”即可。
- 点击物品的名称或价格单元格，可直接修改（按 Enter 保存，按 Esc 取消）。

### 添加配方
- 在“配方 & 利润分析”区域，输入成品名称（需已存在于物品库）。
- 材料清单支持多种格式，例如：
  - `云杉树皮 40, 铁矿石 3, 陶碗 1`
  - `原木1 青铜锭2`
  - `木棍10 羽毛10`
- 系统会提示输入生产建筑（如“铁匠铺”），确认后自动计算成本与利润。

### 调整技能等级
- 使用“技能等级”下拉菜单（0~3级），利润会实时更新，无需重新录入配方。

### 备份数据库
```bash
npm run backup
```
备份文件会保存在 `server/backups/` 目录，文件名包含时间戳。

## 📂 项目结构（关键部分）

```
medieval-dynasty-trade/
├── server/                # 后端服务
│   ├── server.js          # Express API 入口
│   ├── init-db.js         # 数据库初始化脚本
│   ├── database.db        # SQLite 数据库文件（自动生成）
│   └── backups/           # 备份存放目录
├── src/                   # 前端源码
│   ├── components/        # UI 组件（items.js, recipes.js）
│   ├── utils/             # 工具函数（解析、存储等）
│   ├── api.js             # 前端 API 调用封装
│   └── main.js            # 应用入口
├── index.html             # 主页面
├── package.json           # 前端依赖与脚本
└── README.md              # 本文件
```
